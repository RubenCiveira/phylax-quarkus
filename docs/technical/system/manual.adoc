[preface]
== Cómo leer este manual

Este manual describe lo que es común a todo el sistema: arquitectura, conceptos transversales, calidad, operación y convenios.
Lo propio de cada contexto (entidades, casos de uso, flujos) está en `docs/technical/contexts/<contexto>`.
ifdef::module-oauth[]
El servidor OIDC tiene xref:../contexts/oauth/oauth.adoc[su propia documentación técnica].
endif::[]

Toda aplicación tiene los paquetes `bootstrap`, `common` y `features`, y este manual describe lo que comparten. Lo que pertenece a un módulo opcional (como `oauth`) solo aparece si el módulo está declarado en `docs/site-attrs.adoc`.

El *TL;DR* resume lo imprescindible para empezar a trabajar; el resto de capítulos lo desarrollan.
