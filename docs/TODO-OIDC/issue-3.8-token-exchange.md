# 3.8 — Token exchange

- **Fase:** 3 (según necesidad) · **Estado:** pendiente · **Referencia:** RFC 8693.
- **Implementación:** definir política de confianza, actores, audiencia y scopes antes de habilitar el grant.
- **Cierre:** intercambio autorizado funciona; escalada de scopes/actores o audiencia ajena es rechazada.
