OIDC Theme assets and layouts

This directory mirrors the PHP OIDC Theme bounded context structure.

- Application logic lives in `features/oauth/theme/application`.
- Runtime theme layouts and assets are persisted in the document module.
- Bootstrap source assets currently used for seed are in:
  `src/main/resources/install/document/default-theme`.

The `Themes` folder is reserved for filesystem-based theme variants when needed.
